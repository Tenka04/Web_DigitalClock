# Web Digital Clock

A modern and responsive digital clock web application built with HTML, CSS, and JavaScript.

## Features

- Real-time digital clock display
- Clean and modern user interface
- Responsive design that works on all devices
- 24 hour format support
- Smooth animations

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)

## Setup Instructions

1. Clone this repository:
```bash
git clone https://github.com/Tenka04/Web_DigitalClock.git
```

2. Open the project directory:
```bash
cd Web_DigitalClock
```

3. Open `index.html` in your web browser to view the digital clock.

## Usage

Simply open the `index.html` file in any modern web browser to see the digital clock in action.
